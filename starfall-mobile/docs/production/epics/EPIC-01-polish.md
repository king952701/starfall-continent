# EPIC-01 · 表现力打磨（音频 / 画面 / 打击感 / 内容）

> 阶段：Polish。rigor=standard，automation=autonomous。
> 每个 Story 通过标准：代码落地 + 无头用例（或截图）证据 + 不影响既有功能（回归用例全绿）。
> 出包节点：A 组完成、B 组完成、C+D 组完成各出一次 APK（或合并出一次，视改动稳定性）。

## A · 音频（0 → 1）

| ID | Story | 验收 |
|---|---|---|
| **A1** | 音效引擎扩展：音色表（战斗/采集/UI/环境 4 组约 20 个）、同名节流 40ms、并发上限 12、master 加 `DynamicsCompressor`、`Snd.play(name, opt)` 支持音高/音量/声像扰动 | 用例：节流与并发生效；无 undefined 音色；静音开关仍有效 |
| **A2** | 战斗音效挂钩：`swing`（挥砍起手）、`hit`、`crit`、`cast`（按元素变音高）、`die`，挂 `castSkill` / `dealDamage` / 死亡 | 用例：一次完整战斗触发序列正确；连击/群战不糊 |
| **A3** | 采集与成长音效：`mine/chop/herb/fish`（按资源材质）、采集完成、掉落拾取、`level` 升级（补接已定义未调用的升级音）、制作完成 | 用例：四类资源音各不同；升级必响 |
| **A4** | UI 与交互音效：面板开合/切页/购买/出售/装备/开箱/传送/上下船/`thunder`（天气雷声现有视觉无声音） | 用例：关键交互有声；雷声与闪电同帧 |
| **A5** | BGM 程序化编曲：8 区调式映射、和弦+低音+旋律+（战斗）鼓组三层、战斗 intensity 0/1/2、夜间降速、2s 交叉淡入 | 用例：切区域→调式变；进战斗→加鼓；夜间→BPM×0.8；音量沿用 music 总线 |

## B · 画面

| ID | Story | 验收 |
|---|---|---|
| **B1** | DPR 接入：按 `devicePixelRatio`×0.6 折中，移动端上限 2、桌面上限 2、低画质档 `eff=1`，总像素封顶（移动端 1920×1080 / 桌面 2560×1440） | 用例：不同 dpr/qScale 下画布尺寸正确；像素风（smoothing=false）不被破坏；世界/UI 不变形 |
| **B2** | 泛光 + 色调映射：1/4 降采样 → 阈值压暗 → 两次 box blur → `lighter` 叠加；强度按画质档（低 0 / 中 .35 / 高 .6，移动端默认关）；区域色调罩 0.06~0.10 | 用例：关闭时与现状逐像素一致；开启不报错；帧时预算超了自动降级 |
| **B3** | 装备影响外观：`drawChar` 增 `gearLook`（helm/body/cloak/weapon+glow），已装备→映射外观，未装备→退回职业配色；缓存键加 gearHash | 用例：未装备时外观与现状一致；装备不同品质武器外观与发光不同；立绘/角色卡不崩 |
| **B4** | 角色加帧 + 伪骨骼：帧表 4→8（走4/待机2/攻击1/受击1）；躯干/头/双臂/双腿/武器节点化，走路摆臂摆腿、攻击关键帧、施法抬手、受击后仰 | 用例：动画状态机切换正确；攻击时长与技能 CD 不冲突；NPC 加 4 帧走路 |
| **B5** | 贴图：区块内同类格合成图集、2 级预缩放缓存、`Assets.variant()` 加 LRU(256)、加载失败可见提示 | 用例：烘焙结果与现状一致（对照哈希或像素抽样）；缓存不无限增长 |

## 风险登记

| 风险 | 缓解 |
|---|---|
| `drawChar` 签名变化波及立绘/角色卡 | `gearLook` 默认 null + 全调用方同步 + 缓存键升级 |
| 投射物改结算时机影响挂机 | 挂机走独立即时路径，不改 |
| 泛光/DPR 抬高移动端填充率 | 移动端默认关 + 帧时超预算自动降档 |
| 音效高频事件音源爆炸 | 节流 40ms + 并发 12 + compressor |
| balance 搬迁面广 | 逐域迁移，每步比对战力/评分/挂机三项读数 |
