# 批次 ⑪ 采集点随机次数 + 蓝色标签 + 采尽消失 · 证据

日期：2026-10-10 · 结论：**ALL_OK（18/18）** · 方式：Node 无头用例 + 语法检查

## ① 陆地采集资源点头顶蓝色文字

- 画布**屏幕空间**绘制（缩放视野不放大字号），位置：资源**头顶上方 1 格、居中**
- 颜色 **蓝色 `#7fd6ff`** + 黑描边 + 半透明底衬（雪地/沙地浅色地形也看得清）
- 内容 = **资源名 + 剩余可采次数**，例如「松木 ×6」「铜矿 ×3」；渔点次数无限，只显示「渔点」
- 可见范围 4 格并按距离淡出（≤2 格 0.95 / ≤3 格 0.75 / 4 格 0.55），远处不糊屏；单帧上限 40 个
- 靠近交互提示同步显示剩余次数：「E 直接采集 松木（剩 6 次 · 10s）｜ 左键 打开采集面板」

## ② 每个采集点次数随机生成

- `_mkNode`：`cnt = irnd(2, 6)`，`amount = max = cnt` → **每个资源点 2~6 次，各不相同**
- 用例抽样 400 次：取值覆盖 2/3/4/5/6，全部落在 2~6 区间，且 `max` 等于各自随机值（不再是统一 4）

## ③ 次数归零 → 资源点直接消失

- `takeNode` 归零即调 `World.removeNode`：从区块**物件表**与**节点索引**里双双移除 + 触发区块重绘
- 结果：地图模型消失、`nearestNode` 查不到、标签不再显示、无法再交互
- 自动采集任务遇到已消失的点 → 停止并提示「资源点已采尽」（原「采空自动补满」逻辑已删除）
- 采集 / 悬浮面板自动收起，面板文案改为「已采尽（资源点已消失）」
- **不再有倒计时原地刷新**（原 `T_NODE_RESPAWN` 90 秒已移除）；为避免整张图资源被掏空，资源点只在**区块卸载后重新进入时按种子重新**生成

## 用例（18/18）

随机次数分布 / max 跟随 / 采尽移出物件表 / 移出索引 / 触发重绘 / 最近点查询失效 / 任务自动停止 / 蓝色文字存在且含次数 / 渔点不带次数 / 跑图渲染回归

## NOT ASSESSED（需浏览器目验）

- 蓝色字号与题图对比度、4 格淡出的实际观感
- 地图资源随时间消耗后的体验是否需要调整区间（2~6 次）
