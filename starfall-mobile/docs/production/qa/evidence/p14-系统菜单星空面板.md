## 行为说明

- **入口**：功能按钮栏第一格新增「菜单」（四宫格图标），点击弹出 / 收起；面板打开时自动收起生活菜单，避免叠加
- **面板**：天蓝→深蓝渐变 + 两层 CSS 星点（后层 3.2s 缓慢闪烁，纯 CSS 零开销）、发光边框、悬浮上移高亮
- **4×4 布局**：第 1 行 背包/角色/制作/天赋；第 2 行 生活/挂机/地图/导航；第 3 行 拍卖/坐骑/宠物/图鉴；第 4 行 设置/存档（共 14 格）
- **动作分发**：全部复用现有面板开关；**坐骑 / 宠物为预留位**（点击提示「开发中」），后续实现后只需在 `runSysAction` 补一个 case
- **关闭方式**：右上 ×、点击面板外、再次点入口按钮

## 过程中的发现

真浏览器验证中 `bagOpen:false` 为**测试脚本自身 bug**：页面里 `UI` 是顶层 `const`（词法全局），不挂 `window`，`window.UI` 为 undefined 短路了表达式。改用裸 `UI` 后全绿——背包面板打开正常。
