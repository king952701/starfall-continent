## 行为说明

- **菜单栏新增「聊天」喇叭按钮**（megaphone 图标），点击弹出 / 收起聊天窗；桌面端默认收起，触屏设备默认展开（手机没有菜单栏按钮）
- **八向自由拉伸**：边 7px 热区 / 角 14px，Pointer Events（鼠标 / 触摸通用），`touch-action:none` 防触摸劫持
- **尺寸 clamp**：最小 240×150，最大视口 90%；西 / 北方向拉伸用 clamp 后的尺寸反推左上角，位置不跳、min 不卡死
- **记忆**：尺寸 `sf.chat.size`、显隐 `sf.chat.win`，刷新 / 重进恢复；超大存档按视口 90% 收敛
- 发装备链接 / 物品到聊天窗的入口会自动弹出聊天窗（`setChatWin(true)` 统一走一个口）

## 过程中发现与修复

1. **分栏内联 `min-height:0` 压塌聊天窗**：Splitter 通用逻辑给容器写内联 `min-height:0`，聊天窗改 flex 布局后默认高度被算塌到 90px——真浏览器测量发现（computed 0px），在聊天窗分栏挂载后单独覆写 `minHeight=168px` 兜底。
2. `cssRules` 在 file:// 下抛 SecurityError，样式排查改用 computed style 判定。
