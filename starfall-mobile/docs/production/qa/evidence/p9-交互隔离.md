## 第 6 条升级：触摸端隔离（可选 → 必做）

升级日期：2026-10-10 · 用例 **24 条断言 ALL_OK** + 集成回归 ALL_OK

| 浏览器默认触摸行为 | 拦截方式 |
|---|---|
| 页面滚动 / 下拉刷新 | 非白名单区域的 `touchmove`（非被动监听）一律 `preventDefault` |
| 双指 / 三指缩放页面 | `touchstart` 检测到 `touches.length > 1` 立即 `preventDefault` |
| 双指滑动返回上一页 | 同上 + `overscroll-behavior:none` |
| 双击放大页面 | 300ms 内、位移 <30px 的二次轻触 → `preventDefault`（iOS/Android 双击缩放） |
| 长按放大镜 / 长按系统菜单 | `touchforcechange` 拦截 + CSS `-webkit-touch-callout:none` |
| Safari 双指缩放 / 旋转页面 | `gesturestart / gesturechange / gestureend` 三事件拦截 |

**CSS 由「逐个选择器」改为「全场景默认关闭 + 白名单」**：

```css
html,body{-ms-touch-action:none;touch-action:none}
body,body *{-ms-touch-action:none;touch-action:none}
#panelRoot,.pbody,#chatMsgs,#log,#mMenuList{touch-action:pan-y}   /* 白名单：仍可上下滚 */
```

放行为准（避免误伤游戏操作）：

- **输入框 / 文本域 / 下拉框**：`touchmove` 放行（要能选词、拖光标）
- **可滚动区**：面板内容 / 聊天记录 / 日志 / 手机菜单列表
- **交互元素的连点**：`.btn / .cell / button / .pclose / .ctab / .mBtnI / .mbtn / .mMenuBtn` 上的快速二次轻触**不拦**，不挡玩家自己连点
- **游戏自己的双指缩放视野**：不受影响 —— `preventDefault` 只拦浏览器默认行为，同一事件上的游戏回调照常执行（已由集成用例跑图验证）

用例覆盖：双指/三指 touchstart 拦截、单指不拦、同位置双击拦、不同位置不拦、按钮连点放行、面板区放行、`gesture*` 三事件、`touchforcechange`、`touchmove` 三种target、原有 1/4 条无回归、CSS 四条断言、`destroy()` 解绑
