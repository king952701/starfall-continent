## 逐条验收（对应硬性要求 1~8）

| # | 要求 | 结论 | 实现 / 证据 |
|---|---|---|---|
| 1 | 禁止浏览器右键菜单 | **PASS** | `contextmenu` 在 document 上 `preventDefault`；用例「右键菜单被拦截」 |
| 2 | 禁用鼠标手势干扰 | **PASS** | 右键 `mousedown(button===2)` 立即 `preventDefault` + 置 `rightDown`；拖动全程 `mousemove` 也 `preventDefault`；`mouseup` 结束态。左键不拦截（攻击/点击正常）。失焦 / 页面隐藏 / 卸载 → 提示或记标记 |
| 2b | 手势扩展兜底提示 | **PASS** | 拖动中 `blur` / `visibilitychange(hidden)` → 立即弹提示；拖动后 3 秒内 `pagehide` → 写 `localStorage` 标记，下次进游戏提示一次，文案：「检测到鼠标手势扩展可能影响游戏操作，建议在浏览器设置中为本页面关闭鼠标手势功能」 |
| 3 | 禁止文本选中与拖拽 | **PASS** | CSS `user-select:none`（含 -webkit/-moz/-ms 前缀）+ 输入框放行 `user-select:text`；`selectstart`、`dragstart/dragover/drop` 拦截；`img,a,canvas` 加 `draggable="false"`（静态 6 处 + MutationObserver 覆盖运行时新增节点） |
| 4 | 禁止中键与双击干扰 | **PASS** | `mousedown(button===1)` 与 `auxclick(button===1)` 拦截（禁自动滚动 / 新标签打开）；`dblclick` 拦截并清空选区 |
| 5 | 禁止键盘滚动页面 | **PASS** | 空格 / ↑↓←→ / PageUp / PageDown / Home / End 拦截；输入框、下拉框、按钮上的空格放行（保留可访问性），普通按键不拦截 |
| 6 | 触摸端隔离（可选） | **PASS** | `touchmove` 非被动监听并 `preventDefault`（可滚动区 `.pbody / #chatMsgs / #log / #mMenuList` 与输入框放行）；CSS `touch-action:none` 覆盖画布 / HUD / 摇杆 / 触屏按钮 |
| 7 | 布局隔离 | **PASS** | `html,body{width/height:100%;overflow:hidden}`（原有）+ 新增 `overscroll-behavior:none`（禁下拉刷新与滑动返回）；画布 `#cv{position:absolute;inset:0;100%}` 铺满视口 |
| 8 | 事件集中管理 + 中文注释 | **PASS** | 所有监听统一走 `Interlock.bind()` 登记到 `handlers`（16 条），可用 `destroy()` 全量解绑；每处 `preventDefault` 均有中文注释说明拦截目的 |
