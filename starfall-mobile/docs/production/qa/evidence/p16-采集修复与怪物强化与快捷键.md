## 一、采集头顶黑块（根因修复）

- **根因**：黑块不是画错，而是屏幕正中偏下（top:56%）的 DOM 元素 `#progWrap`——300px 宽近纯黑底的进度条，玩家采集时必站屏幕中心，条恰好悬在人物头顶，填充 0% 时就是一块黑。
- **修复**：删除 `#progWrap`（DOM + CSS + 设置布局目标），进度条改为 **Canvas 屏幕空间绘制在资源点上方**（`drawGatherBar`：56px 金色条 + 黑描边剩余秒数），人物头顶从此干净。
- 顺带修复审查发现的**交互提示文字画在底板外 44px** 的错位（`y-62` → `py-62`）并加黑描边。

## 二、怪物放大 2 倍 + 头顶血条

- `drawMonster` 的 `wpx` 表达式 ×2：精灵、影子、死亡翻转帧、选中圈一次联动放大；玩法判定半径（攻击距离/点选）不变，只放大视觉。
- 血条由「受伤后才显示」改为**常显**：黑底 + 阵营色（boss 红 / 精英橙 / 普通蓝）+ 白描边；名牌 Lv.x 加黑色描边，亮色地形可读。

## 三、采集可被打断

- **移动打断**：`movePlayer` 有移动输入即 `interruptGather`（与批量任务行为对齐）。
- **受击打断**：`updateGather` 记录开始时血量，任何伤害（怪物攻击 / 直伤 / Boss 技能全覆盖）使血量下降即中断，日志提示。
- 离开 3.2 格 / 资源采尽等原有取消路径保留。

## 四、设置面板「快捷键 / Hotkeys」标签区（PC）

- 16 项可重绑：交互/背包/角色/制作/天赋/生活/挂机/地图/总览/成就/图鉴/排行榜/拍卖/设置/快喝药水/翻滚。
- 点击键位按钮 → 「按下新按键…」→ 按键即生效并持久化到 `sf_settings_v1.hotkeys`；**Esc 取消、固定键位（WASD/1-6/Esc/Enter）拒绑、冲突拒绑（提示已绑定动作）**。
- `bindInput` 全部改查表（`Settings.data.hotkeys` 回退默认键）；「恢复全部默认设置」会一并还原快捷键。

## 五、子代理审查报告 → 已应用 9 项 UI 优化

1. 面板圆角 10px 统一（.panel / .pbody 底角），与浮层一致

4. 全局暗色细滚动条（此前深色面板配系统亮灰滚动条）
5. `#tooltip` z-index 60→75（此前被资源导航弹窗盖住失效）
6. `.tab` 补 hover、`.btn` 补 :active 按下态、`.pclose` 热区扩到 26px + active 态
7. 图标尺寸统一 18px（系统菜单 20px / 手机菜单 16px → 18px）
8. 9px 超小字（快捷栏底标、技能名）→ 10px
