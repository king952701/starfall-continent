# 批次 ⑥ 野外随机宝箱 + 采集资源名称显示 · 证据

日期：2026-10-10 · 结论：**ALL_OK** · 方式：Node 无头用例

## 资源名称（8 项）

```
PASS 2 格内资源头顶画出金色名称（煤炭 / 水晶…）
PASS 名称与资源一致
PASS 文字画在资源正上方约 1 格处（Δx=1, Δy=0）
PASS 离开 2 格后不再显示（不会满屏都是字）
PASS 已采尽的资源不再顶着名字
PASS 大量资源时调用无异常
PASS 回归：跑图 + 渲染无异常
```

- 屏幕空间绘制 → **字号不随视野缩放变大变小**
- 黑描边 + 半透明底 → 雪地/沙地等浅色地形上也看得清
- 单帧最多 24 个标签（保帧率）；钓鱼点显示「渔点」

## 野外宝箱（10 项）

```
PASS 开箱得金币（0 → 1550）      PASS 统计 +1
PASS 背包得到物资                PASS 记录已开坐标到 CHEST_OPENED
PASS 2 分钟内重复开箱不再产出（提示：宝箱已空）
PASS 精致宝箱每次都出金币（最少 +1500）  PASS 精致宝箱物资发放正常
PASS 村落宝箱仍可正常开启        PASS 村落宝箱不写入野外开启记录
PASS 开启记录有清理机制（513 条，超 400 条时清掉 10 分钟前的旧记录）
```

## 密度（全图抽样 625 区块 / 陆地 427）

| 指标 | 实测 |
|---|---|
| 陆地区块有宝箱 | **38%**（每 2~3 个陆地区块一处） |
| 精致宝箱占比 | 19 / 161 ≈ 15% |
| 落点合法性 | 0 个落在水里 / 山体 / 障碍上 |
| 位置确定性 | 同种子下位置固定 |

产出：金币 + 必掉装备（精致箱更高品质）+ 材料药材 + 生命/魔力药水或食物 + 经验；精致箱金币 ×3、材料次数 5 次、必给药水。

**NOT ASSESSED**：真实地图里宝箱的"好不好找"手感、资源名标签在小屏上的拥挤程度 —— 需真机试玩确认。
