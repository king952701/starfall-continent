# UX 规格 · 天赋树图 / 设置项 / 大地图

## 1. 天赋树：从 DOM 网格 → Canvas 树状图

现状（`14_ui.js:1141-1181`）：4 列 DOM 网格，节点卡，**无连线、无缩放、无预览**，每次点击整面板重建（`:1165`）。

### 1.1 目标形态

- 单张 Canvas（尺寸随面板，DPR 感知），4 棵树按纵向分区，节点按 `tier` 分行
- **前置连线**：`pre:{id,lv}` → 当前节点，贝塞尔曲线；已满足绿色实线、未满足灰色虚线
- **节点三态**：已点（金边+填充等级点）/ 可点（亮色+脉冲）/ 锁定（暗色+锁纹）
- **交互**：
  - 点击节点 → 加点（长按连续加，间隔 120ms）；右键/双指 → 减点（未保存前）
  - 滚轮 / 双指捏合缩放 0.5×~1.8×，空白处拖拽平移
  - hover/点击显示 tooltip（名称、当前等级/上限、每级效果、前置、消耗）
  - 顶部 4 个 tab 快速定位到树，右侧显示剩余点数与重置按钮
- **键盘可达**：Tab 遍历节点，Enter 加点，`+/-` 缩放，方向键平移（无障碍要求）
- 保留现有面板框架（`.panel > .ptitle + .pbody`），只替换内容区实现

### 1.2 数据

**不改存档结构**：继续用 `player.talents = {id: lv}`，`07_talents.js` 的 `mods/special/pre` 原样读取。
节点布局坐标：按 `tree` 分列（4 列），`tier` 为行，同 tier 内按数组顺序横向排布；坐标在打开面板时计算并缓存（数据结构不变 → 无 schema 变更）。

## 3. 大地图：真实地形采样 + 迷雾

### 3.1 真实采样（低风险，先做）

现状：`14_ui.js:1221-1265 openMap()` 画 8 个**矩形色块**，与实际地形不一致。
改为：按 `world.tileInfo()` 在网格上采样（步长 8 格 → 1500×1500 采样点太多，**降采样到 480×480 画布：每像素采样 25 格取多数地表**），水/山/林/沙/雪按区域调色板上色，一次性烘焙到离屏 canvas 并缓存（世界不变 → 只算一次）。

### 3.2 迷雾（⚠️ 存档 schema 变更 → **需批准**）

| 方案 | 做法 | 影响 |
|---|---|---|
| A（推荐） | 存档新增 `explored: Uint8Array/Set`（按区块 key，12000/16=750×750 → 位图 70KB） | **新增存档字段**，旧档读取时视为全未探索（不丢档，只是雾重来） |
| B | 存 Settings（不随存档走） | 不碰存档，但换设备/清设置丢失 |
| C | 不持久化，本次会话内有效 | 零风险，但每次进游戏重新黑图 |

- 视觉：未探索区域 `rgba(6,9,18,.88)` 覆盖，已探索按最后一次可见时间淡化（可选）
- 小地图同步同一份数据
- **自动驾驶模式下此项 BLOCKED，等你选 A/B/C**

## 4. 通用无障碍与一致性
