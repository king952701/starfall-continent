# 星落大陆 · 系统索引与阶段定位

## 1. 定位与栈

| 项 | 值 |
|---|---|
| 类型 | 2D 开放世界沙盒 RPG（采集 / 制作 / 战斗 / 挂机 / 交易） |
| 渲染 | Canvas2D 手绘程序化美术 + DOM 面板（`#panelRoot` 内 17 个面板） |
| 世界 | 12000×12000 格（TILE_PX=32，CHUNK=16），区块流式生成 + 烘焙缓存 |
| 打包 | Cordova（`starfall-mobile/`）→ Android APK，约 3.6MB |
| 存档 | localStorage（纯本地，无账号 / 无服务端） |

## 2. 阶段判定

已具备：世界生成、战斗、技能、天赋、装备、制作、挂机、拍卖、家园、天气、昼夜、移动适配、APK 出包。
判定：**Production 完成 → 进入 Polish（打磨）**。缺的不是玩法，是**表现力与反馈**：音效为 0、无后处理、装备不影响外观、技能特效是几何形、天赋无树图。

## 4. 本次打磨的四个 Epic

| Epic | 内容 | 为什么现在做 |
|---|---|---|
| **A 音频** | 音效从 0→1（战斗/采集/掉落/升级/UI/环境）+ 程序化 BGM（区域/战斗/昼夜变奏） | 反馈层完全空白，投入产出比最高，零素材零版权风险 |
| **B 画面** | DPR 接入、泛光+色调映射、装备影响外观、角色加帧 | 高清屏糊、装备无成长可视反馈 |
| **C 打击感** | 投射物、粒子、命中顿帧、伪骨骼关节、天赋树状图 | 技能现在只有 circle/cone/beam 三种即时几何 |
| **D 内容** | 大地图真实采样、POI 多样化、NPC 走路帧、balance.js 集中 | 内容密度与可维护性 |

## 5. 证据与停点

- 视觉/听觉改动：**无头用例（Node 桩 DOM/Canvas）+ 构建产物自检**，重要项真机截图存 `production/qa/evidence/`（本机无浏览器截图工具时**如实标注 NOT ASSESSED**，不伪造观察结论）
- **必须停下询问的三类**：删除既有代码、范围变更、**存档 schema 变更**（当前唯一已知：大地图迷雾需要新增已探索集合字段，见 `design/ux/ux-spec.md`）
